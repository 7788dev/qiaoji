# 使用指南

[返回首页](../README.md) · [界面预览](screenshots.md)

## 打开与保存

启动后可以直接在空白文档中输入。第一次保存时选择位置；已有文件使用 `Ctrl+O` 打开，无需先打开文件夹。

| 操作 | 快捷键 |
| --- | --- |
| 新建文档 | `Ctrl+N` |
| 打开文件 | `Ctrl+O` |
| 打开文件夹 | `Ctrl+Shift+O` |
| 保存 / 另存为 | `Ctrl+S` / `Ctrl+Shift+S` |
| 关闭当前文档 | `Ctrl+W` |
| 切换标签 | `Ctrl+Tab` / `Ctrl+Shift+Tab` |
| 导出 | `Ctrl+Shift+E` |

默认手动保存。标签旁的小圆点和底部状态提示表示有未保存修改。切换标签、模式或窗口焦点不会写入文件。可在「文件」菜单选择「全部保存」。

关闭未保存文档时：

| 选择 | 结果 |
| --- | --- |
| 保存 | 写入成功后关闭；取消文件对话框或写入失败会保留窗口 |
| 不保存 | 放弃本次修改并关闭，原文件保持不变 |
| 取消 | 继续编辑，保留当前内容 |

退出应用会依次处理所有未保存文档，不会因等待时间较长而强制退出。下次启动恢复已保存文件的标签、编辑模式、选区与阅读位置；未保存草稿需要在关闭前保存。

## 编辑与排版

正文默认直接呈现 Markdown 排版。输入 `# `、`- `、`> ` 等标记开始标题、列表或引用，也可以从「格式」菜单操作。表格、图片、链接和公式的局部控件会在编辑对应内容时出现。

| 操作 | 快捷键 |
| --- | --- |
| 加粗 / 斜体 | `Ctrl+B` / `Ctrl+I` |
| 行内代码 / 链接 | `Ctrl+E` / `Ctrl+K` |
| 一级至六级标题 | `Ctrl+1` … `Ctrl+6` |
| 普通段落 | `Ctrl+0` |
| 任务项 | `Ctrl+Shift+L` |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Y` |
| 可视化 / 源码 | `Ctrl+/` |

每篇文档拥有独立的撤销记录，切换标签不会重置。源码模式编辑完整文件，包括 front matter。

仅打开、切换模式或无修改保存不会重写原始文件。可视化编辑后，正文可能转换为等价 Markdown 写法；front matter、BOM 和换行风格保留。原始 HTML、引用定义和不能可靠转换的扩展语法保留在源码模式中，不执行 HTML。超过 1 MB 的文件默认使用源码模式，单文件上限为 8 MB。

## 字号与缩放

在「视图 → 设置」中分别调整：

- **正文字号**：默认 16px，只调整编辑内容。一级标题为正文的 2 倍，二级标题为 1.5 倍。
- **行高与正文宽度**：默认 1.75 倍行高、760px 正文宽度。
- **应用缩放**：默认 100%，同时调整菜单、标签、侧栏和正文；Windows 自身的显示缩放仍然生效。

如果菜单和文字一起变大，按 `Ctrl+Alt+0` 或选择「视图 → 恢复 100% 缩放」。非默认缩放时，底部会显示当前百分比，点击即可恢复。`Ctrl+0` 仍用于将标题改为普通段落。

## 文件树、大纲与搜索

「文件 / 大纲」共用侧栏。拖动侧栏边缘调整宽度，按 `Ctrl+\` 显示或收起；窄窗口中侧栏以抽屉展开。文件夹按需读取，切换文件夹不会关闭已经打开的文档。

| 操作 | 快捷键 |
| --- | --- |
| 文档内查找 / 替换 | `Ctrl+F` / `Ctrl+H` |
| 文件夹全文搜索 | `Ctrl+Shift+F` |
| 显示 / 隐藏侧栏 | `Ctrl+\` |
| 设置 | `Ctrl+,` |

点击大纲标题跳转到正文位置。全文搜索针对当前打开的文件夹；磁盘变动会更新本地索引。

## 图片、链接与导出

粘贴或插入图片后，图片先暂存。保存文档时，图片写入文档旁的 `assets/`，Markdown 使用相对路径引用。跨目录另存为会复制本地图片并更新引用，保留原文件及原附件。

相对图片和 Markdown 链接按当前文档位置解析。可按住 `Ctrl` 点击正文链接，或使用链接浮层打开目标；已打开的文档会复用原标签。

「文件 → 导出」支持 HTML、PDF、Word 和纯文本，使用当前编辑内容。要保存 Markdown 副本，请使用「另存为」。

## 外部修改

磁盘文件发生修改时，巧记检查当前文档是否存在未保存内容。出现冲突后，编辑缓冲区会保留，并提供以下操作：

| 操作 | 作用 |
| --- | --- |
| 重新加载 | 读取磁盘版本；有未保存内容时先确认放弃 |
| 另存为 | 将当前编辑内容保存到另一位置 |
| 覆盖磁盘 | 明确确认后用当前内容覆盖已检测到的磁盘版本 |

确认期间若磁盘再次变化，会重新要求处理冲突。磁盘文件被移动或删除时，仍可将当前内容另存为。

## 文件与数据

```text
文档所在目录/
├─ *.md                 普通 Markdown 文件
├─ assets/              保存图片时按需创建
└─ .qiaoji/trash/        删除文件时按需创建

%APPDATA%/巧记/
├─ settings.json        偏好、窗口与文档恢复信息
└─ indexes/             可重建的搜索缓存
```

打开目录不会生成初始化标记或示例笔记。文档通过规范化路径识别，不依赖 front matter 的 `id`。修改一级标题不会重命名文件。

删除操作将文件移入可恢复回收站，可从「文件 → 回收站」还原。旧版笔记、附件和回收站继续可用。升级后首次迁移将保存方式设为手动，其余偏好保留；需要时可在设置中开启自动保存。
