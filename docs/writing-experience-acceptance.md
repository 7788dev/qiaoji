# 写作体验验收：1.1.1

日期：2026-09-08。桌面验证使用独立的临时 APPDATA 和合成 Markdown 文件，没有使用个人笔记。此前的安全与性能修复一并保留。

## 实现范围

- 单侧栏共用文件树与大纲，默认宽度 240px，可调整、收起，窄窗口使用抽屉。顶部为文件、编辑、格式、视图、帮助菜单，多个文档使用轻量标签。
- Milkdown Crepe 固定为 7.22.1，正文直接编辑；CodeMirror 源码模式编辑完整文件。关闭块拖拽、斜杠菜单和浮动格式工具栏。
- 正文默认 16px、行高 1.75，一级／二级标题为 32px／24px，应用缩放默认 100%。使用 WebView2 原生光标；关闭额外的浏览器缩放，防止与应用缩放叠加。非默认比例显示百分比，支持点击或 Ctrl+Alt+0 恢复 100%。
- 文档会话支持无路径草稿与任意位置的 Markdown 文件。文件夹仅用于导航和搜索，文档按规范化路径去重。
- 默认手动保存，切换标签、模式和失焦不写入原文件。关闭与退出处理保存、不保存、取消，删除了等待 8 秒后强制退出的逻辑。
- 串行写入、原子替换、revision 冲突检查；覆盖仅针对已经确认的磁盘版本，再次外部修改会要求重新处理。
- 无修改保存保持文件字节和修改时间；富文本编辑保留 front matter、BOM、换行风格和图片说明。原始 HTML、引用定义及无法安全转换的扩展语法保留在源码模式。
- 图片先暂存，保存时写入文档旁的 assets；跨目录另存为复制本地图片，保留原文件与附件。相对文档链接按当前文档的位置解析。
- 已保存标签、当前文档和阅读位置可恢复；旧设置首次迁移为手动保存，其余偏好保留。搜索缓存位于应用配置目录，普通目录不生成标记或示例文件。
- 网格、收藏、标签管理、模板和性能诊断入口已从主界面移除。保留查找替换、全文搜索、大纲、字数、导出和可恢复删除。
