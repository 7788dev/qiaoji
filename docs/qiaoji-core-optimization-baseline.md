# 巧记核心优化实施基线

记录时间：2026-08-22（Asia/Shanghai）

## 当前范围

本版本聚焦本地 Markdown 笔记。Hexo 扩展已从后端包、Wails API、配置模型、前端入口、
运行时面板和生成资源中移除。旧 `settings.json` 中的 Hexo 字段会被 Go 的 JSON 解码器
忽略，并在下一次保存设置时自然淘汰；现有 Markdown 笔记、附件和用户选择的 vault 不会
被迁移或删除。

## 防呆与体验改进

- 文件夹重命名返回后端实际采用的规范化相对路径，当前文件夹筛选及其子目录筛选会同步迁移。
- 笔记、文件夹和标签的空白名称在前端直接拦截，避免无效请求和空列表状态。
- 删除继续使用可恢复回收站，并保留撤销入口。
- 索引、列表分页、后台校准和编辑器保存队列维持原有性能优化，避免重命名或外部变更时覆盖未保存内容。

## 当前质量门禁

```text
gofmt -l .                     PASS（无输出）
go vet ./...                   PASS
go test ./...                  PASS
npx tsc --noEmit               PASS
npm test -- --run              PASS（8 files，57 tests）

```

旧版 Hexo 验收截图和一次性 fixture 不属于运行时资源；它们不会被应用读取。发布前可在
确认不再需要历史验收证据后，由维护者手动清理这些未跟踪产物。
